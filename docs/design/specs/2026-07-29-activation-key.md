# Activation Key implementation

**Datum:** 2026-07-29
**Status:** Brief for code subagent
**Scope:** License activation system

## Goal

PlexusX will not start without a valid activation key. The user (you) generates a small batch of keys offline and hands them to beta testers. The key is bound to a single PC; the user can reset their PC hardware freely but the key only works on one machine at a time.

## User decisions

- **No key = no launch.** App refuses to start without a valid key (shows blocking modal, not a toast).
- **4 keys total**, generated by the engineer and delivered to the user via `dotsnine` console command.
- **Master key embedded in source.** Salted + 100k KDF iterations so decompiling doesn't trivially reveal it.
- **Distribution model:** Manual hand-out. No store, no online activation, no LemonSqueezy, no Stripe.
- **UI:** When license is missing or invalid, only `Account` tab is enabled. Other tabs are hidden. Once a valid key is entered, all tabs become accessible.

## Key format

```
PPPP-T-RRRR-XXXXXXXX-XXXX
│   │ │    │        └─ 4-char checksum (HMAC-SHA256 truncated, base32)
│   │ │    └────────── 8-char random body (49-bit entropy, base32)
│   │ └─────────────── 1-char tier (F = free, T = trial, P = paid)
│   └────────────────── 1-char release marker (R = release, B = beta)
└────────────────────── 4-char year+month packed (e.g. 9H7L = 2026-07, base32)
```

Total: 5 groups separated by `-`, 28 characters with dashes, 22 chars of entropy. Base32 alphabet: `ABCDEFGHIJKLMNOPQRSTUVWXYZ234567` (no 0/1/I/O confusion).

## On startup flow

1. `Program.Main` reads command-line args.
2. If first arg is `--tier <free|trial|paid>`, run `KeyGenerator.Program` and exit.
3. Else: `new LicenseService()`. Read `%LocalAppData%\PlexusX\license.json`.
4. If license exists and `TryValidate()` returns `Valid`, continue to `MainWindow`.
5. If license is missing or invalid, show `LicenseDialog` modally.
   - User pastes key, clicks Activate.
   - On `Valid`: save JSON, dialog closes, app continues.
   - On `Invalid`/`Expired`/`Tampered`: show error inline, leave dialog open.
   - Only **Close Application** button if invalid (user can't skip; they must enter a valid key).

## Tamper protection

- License JSON signed with HMAC-SHA256 over the inner JSON. JSON parses only if file is exactly two top-level fields: `payload` (string) + `sig` (base32). Modifying either breaks validation.
- Hardware fingerprint: SHA-256 of `(CPUID + DiskSignature + WindowsInstallID)`. Stored in license JSON at activation. Validated on every load.
- Tick-count past activation: embedded absolute deadline encoded in key (year-month from base32). Loaded license checks remaining days.
- Debugger detection: `Debugger.IsAttached`. If true, the app raises `LicenseState.Tampered` even if the key is valid.
- File presence paranoia: if license.json is missing OR has wrong size OR decode fails, treat as Tampered.
- All errors are logged to `%LocalAppData%\PlexusX\crashes\license-fail.log` (timestamp + state + reason).

## Anti-debug

- `Debug.Assert` not used (compile disabled in Release).
- `Debugger.IsAttached` short-circuits validation.
- `Process.GetProcessesByName("dnSpy")`, `("x64dbg")`, `("fiddler")` checked at startup. If any found, raise Tampered.
- `Environment.StackTrace` doesn't contain Visual Studio indicators.

## Master key + KDF

```csharp
internal static class LicenseKeyDerivation
{
    // Salted + iterated HMAC. Anyone decompiling the binary can see this but they
    // can't easily reverse the KDF without running it.
    private static readonly byte[] Salt = new byte[]
    {
        0x5A, 0x71, 0xE1, 0x4C, 0xF3, 0x88, 0x09, 0xB2,
        0xD7, 0x6A, 0x5B, 0x44, 0x91, 0xC8, 0x12, 0xA7,
    };

    private static byte[] MasterKey()
    {
        // 100,000 iterations of HMAC-SHA256 over a fixed input. The result is the
        // "master key" used to verify signatures. Slow on purpose so a brute-force
        // search of the keyspace is impractical.
        var kdf = new byte[32];
        for (int i = 0; i < 100_000; i++)
        {
            using var hmac = new HMACSHA256(Salt);
            // input is kdf || i (4 bytes LE)
            var input = new byte[kdf.Length + 4];
            Buffer.BlockCopy(kdf, 0, input, 0, kdf.Length);
            BitConverter.GetBytes(i).CopyTo(input, kdf.Length);
            kdf = hmac.ComputeHash(input);
        }
        return kdf;
    }
}
```

## Validation pipeline

```
public LicenseState TryActivate(string keyString)
{
    // 1. Parse key
    var key = LicenseKey.Parse(keyString);
    if (key is null) return Invalid;

    // 2. Reconstruct payload string
    var payload = $"{key.YearMonth}-{key.ReleaseMarker}-{key.TierMarker}-{key.Body}";

    // 3. Verify HMAC-SHA256(payload, master_key) == key.Checksum (base32 encoded)
    if (!LicenseKeyDerivation.VerifySignature(payload, key.Checksum))
        return Tampered;

    // 4. Compute current hardware fingerprint
    var currentHw = LicenseKeyDerivation.GetHardwareFingerprint();
    var encodedHw = LicenseKeyDerivation.HashAndEncode(currentHw);

    // 5. Save license
    var record = new LicenseRecord { Payload = payload, Signature = key.Checksum };
    LicenseKeyDerivation.SaveRecord(record, encodedHw);
    _current = record;
    _state = Valid;
    return Valid;
}
```

On load (no activation needed):
```
public LicenseService()
{
    var record = LoadRecord();
    if (record is null) { _state = Invalid; return; }
    if (Debugger.IsAttached) { _state = Tampered; return; }
    if (HasForbiddenProcess()) { _state = Tampered; return; }

    var payload = record.Payload;
    if (!VerifySignature(payload, record.Signature)) { _state = Tampered; return; }

    var savedHw = ExtractHardwareId(payload);
    var currentHw = GetHardwareFingerprint();
    if (savedHw != HashAndEncode(currentHw)) { _state = WrongMachine; return; }

    if (IsExpired(payload)) { _state = Expired; return; }

    _state = Valid;
}
```

## Hardware fingerprint (Windows)

```csharp
private static string GetHardwareFingerprint()
{
    var sb = new StringBuilder();
    foreach (var mo in new ManagementObjectSearcher("SELECT ProcessorId FROM Win32_Processor").Get())
    {
        sb.Append(mo["ProcessorId"]);
    }
    var diskSerial = "";
    try
    {
        using var searcher = new ManagementObjectSearcher("SELECT SerialNumber FROM Win32_DiskDrive WHERE Index=0");
        foreach (var mo in searcher.Get())
        {
            diskSerial = mo["SerialNumber"]?.ToString() ?? "";
        }
    }
    catch { /* disk query may fail in some VMs */ }
    sb.Append(diskSerial);
    sb.Append(Environment.MachineName);
    return HashAndEncode(System.Text.Encoding.UTF8.GetBytes(sb.ToString()));
}
```

## YearMonth expiry

- Issued: `9H7L` decodes to `2026-07`. Free tier = 12 months, Trial = 7 days, Paid = 24 months.
- Hard-coded in `LicenseKeyDerivation.GetExpiryMonths(tier)`.
- After expiry, license shows `Expired` but the app still shows the Account tab. User can re-enter a fresh key.

## License dialog bound to MainWindow

When `LicenseService.HasValidLicense == false`:
- MainWindow constructor does NOT create heavy pages (`_vibrancePage`, `_settingsPage`, etc.); only `_accountPage` and the dialog are created.
- After license activation, the dialog closes; the heavy pages are constructed lazily on first navigation.

This avoids loading time on a non-activated user.
