## Bug found and fixed this session

### Alt-tab saturation disappears (the user's reported issue)

**Root cause.** Two stacked problems:

1. `MainWindow.OnDeactivate` (added in commit `dd64dce`) called
   `_engine.SuspendOverlay()` on every focus loss. SuspendOverlay sets a
   `_overlaySuspended` flag AND calls `_overlay.Clear()` (writes identity
   matrix → no tint). The intent was "don't make the user think PlexusX is a
   stuck overlay when they alt-tab to Outlook" — but for the actual use case
   (saturate my game, alt-tab back to the game), it broke the one thing the
   app exists to do.

2. `VibranceEngine.ScheduleOverlayApply` did not check `_overlaySuspended`.
   Any value change while suspended would silently re-enable the overlay
   underneath the user's back, making the suspend flag worthless.

**Fix.** Reverted the MainWindow auto-suspend wiring (engine keeps the API
for future opt-in use). Added the missing `if (_overlaySuspended) return;`
guard to `ScheduleOverlayApply` so the suspend flag, if anyone ever calls it,
will now actually keep the overlay off until ResumeOverlay.

**Regression tests** added:

- `SuspendOverlay_StopsSubsequentValueWrites_UntilResume` — locks in the
  invariant that a value change while suspended never re-applies the
  overlay, and ResumeOverlay flushes exactly once.
- `VibranceSlider_Drag_EngineUpdates_ValueDuringDrag_FlushOnEndDrag` — keeps
  the BeginDrag / EndDrag chip-tracks-cursor-1:1 contract honest against
  future refactors.

## Critical non-code items blocking paid launch (per docs/ROADMAP.md)

These are the real ship blockers for Phase 2 (paid launch). The code is
ready; the business infrastructure isn't:

1. **EV code-signing certificate** (~€200-400/yr). Without it, every
   installer download shows "Unknown publisher" and users delete the file.
2. **Privacy policy on a public URL** (GDPR).
3. **Terms of service / EULA** shown in the installer.
4. **Merchant-of-Record account** (LemonSqueezy or Paddle) — handles EU VAT
   + refund disputes.
5. **License-key activation flow** in PlexusX.
6. **In-app "Go Pro" button** deep-linking to checkout.
7. **Trial logic** (30-min cumulative lockout, per HANDOFF spec).
8. **Webhook** for paid users to receive keys automatically.
9. **Landing page** (Vercel/Netlify free tier).
10. **Discord server** + bug-report channel.
11. **Pre-launch smoke** on a clean Win 10 install.

The PlexusX code is **fit for Phase 1 (free public beta)** — all the
existing surface is exercised in this QA pass and passes. **Not fit for
Phase 2 (paid launch)** until the 11 items above are unblocked.
